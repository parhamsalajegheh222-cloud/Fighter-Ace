SKY ACE — Website / Installable Web App

PUBLISH AS A WEBSITE (GitHub Pages)
1. Create a public GitHub repository named sky-ace.
2. Extract this ZIP and upload all files inside it to the repository root.
3. In the repository, open Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to show your public website URL.

INSTALL ON ANDROID
1. Open the published HTTPS URL in Chrome.
2. Open Chrome's three-dot menu.
3. Choose Install app or Add to Home screen, if offered.

PACKAGE CONTENTS
- index.html: SKY ACE game
- manifest.webmanifest: install settings
- service-worker.js: offline caching after first visit
- icon-192.png and icon-512.png: app icons

A public link requires hosting. This package prepares the site but does not create a public URL on its own. HTTPS hosting is required for install/offline features.
